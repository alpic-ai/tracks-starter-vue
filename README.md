# Vue starter

A minimal single-page Vue app in TypeScript built with Vite, no router and no store.

- `index.html`: the page
- `src/main.ts`: the entry point
- `src/App.vue`: the root component
- `src/assets/main.css`: global styles
- `vite.config.ts`: Vite configuration

## Run

```sh
npm install
npm run dev
```

Then open http://localhost:5173.
